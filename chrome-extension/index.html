Chrome extension

Pin live website data in Chrome.

LivePin keeps selected website values in a persistent side panel or draggable floating pin so the data can stay with you when the source tab does not.

A browser-side live data tracker

LivePin is designed for values that are small but important: a score, price, count, percentage, statistic, status or KPI. Instead of building a custom API integration for every website, you select the value from the page and LivePin stores the information needed to read it again.

Persistent Side Panel

Your pins live together in Chrome's Side Panel with current value, source status, refresh controls, local history, groups, search and edit actions.

Floating website values

Floating is optional per pin. When enabled, a pin can stay visible over other webpages and can be dragged to the part of the viewport that works for you.

Alerts for meaningful changes

Optional conditions can trigger visual feedback, sound, Chrome notifications or a user-configured webhook. Notification and webhook access are requested only when those channels are enabled.

Privacy and permissions

LivePin asks for access when you choose to track a site. It is local-first and does not require a LivePin account. Read the Privacy Policy and technical overview before installing if you want the details.
