LivePin Support

Help with installation, pins, website access, refresh compatibility, floating values and alerts.

Before reporting a problem

  • Open chrome://extensions and confirm LivePin is enabled.
  • Open the source page and use Refresh on the affected pin.
  • If a site changed its layout, edit or recreate the pin so LivePin can capture a fresh selector fingerprint.
  • Check whether the pin reports a source/compatibility warning rather than assuming a stale value is live.

Website compatibility

Some sites can limit background refresh because of authentication changes, CAPTCHA, CSP/iframe restrictions, network behavior or client-side rendering. See How LivePin works for the refresh model.

Permissions

Site access is requested when you choose to track a value there. All-sites access is requested when you enable Floating for a pin. Notification permission is requested only for notification alerts.

Report an issue

Please describe what you expected, what happened, the website hostname, and the LivePin version. Do not post passwords, session tokens, private page content, or exported tracker data in a public issue.
