Support

Help with LivePin installation, pins, permissions, and alerts.

Before reporting a problem

  • Open chrome://extensions and confirm LivePin is enabled.
  • Reload the extension after installing a newer unpacked build.
  • Open the source page and use Refresh on the affected pin.
  • If a site changed its layout, edit or recreate the pin so LivePin can capture a fresh selector fingerprint.

Permissions

Site access is requested only when you pin a value there. All-sites access is requested only when you enable Floating for a pin. Notification permission is requested only for notification alerts.

Report an issue

Please describe what you expected, what happened, the website hostname, and the LivePin version. Do not post passwords, session tokens, private page content, or exported tracker data in a public issue.
