How it works

From a website value to a browser pin.

LivePin combines a visual picker, browser-side source refresh, local history and optional alert rules.

1. Pick a value on a page

Open the source page, start LivePin's picker and click the exact value. LivePin records a selector/fingerprint and tests background compatibility before the tracker is saved.

2. Refresh with the best browser-side source available

While a source page is open, LivePin can observe live DOM changes. For background refresh it can try raw HTML, browser-side rendered parsing and discovered request data where available. It does not guarantee that every site can be refreshed in the background.

3. Store history locally

Tracker configuration is stored in Chrome extension storage. Value history stays in extension IndexedDB by default and retention can be adjusted in Settings.

4. Add conditions and alerts

Rules can react to a value changing or matching configured comparisons. Visual and audio channels are local. Chrome notifications and webhook delivery are optional and request their permissions only when enabled.

5. Keep selected pins floating

Floating is configured per pin. A floating pin can be dragged to a preferred location and its position is persisted. Enabling floating requires broader host access because the chosen pin must render over other normal webpages.

Known compatibility limits

Authentication changes, browser scheduling, CAPTCHA, cross-origin redirects, CSP/iframe rules and app-specific rendering can prevent a background refresh. LivePin reports source status rather than pretending a stale value is live.

Test LivePin without an account

The public LivePin demo page contains changing local values specifically for trying the picker.
