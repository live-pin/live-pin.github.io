# LivePin website

Official website for **LivePin — Pin & Track Live Website Data**:
**https://live-pin.github.io/**

The site is static, dependency-free and served with GitHub Pages.

## Search and discovery

- Canonical metadata, Open Graph and Twitter/social preview metadata on public pages.
- Schema.org Organization, WebSite, SoftwareApplication, FAQPage, HowTo, WebPage and breadcrumb data.
- High-intent product pages for website value tracking, live data tracking in Chrome and how LivePin refresh/alerts work.
- XML sitemap plus plain-text sitemap.
- `robots.txt` explicitly allows Googlebot, Bingbot and OAI-SearchBot.
- `llms.txt` provides a machine-readable product and canonical-page map.
- `.well-known/security.txt` provides a stable public security/support contact.

The previous GitHub Pages URL should keep these pages with canonical URLs pointing to `https://live-pin.github.io/` so search engines consolidate onto the new site.
